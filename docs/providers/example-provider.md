# Provider-neutral example

1. Configure `fixture-provider` and its credential in a non-repository CCR test
   instance.
2. Set a non-secret route selector and verified effective model identity in a
   local deployment file.
3. Select the compatibility profile by capability evidence.
4. Run offline validation, local plugin detection, a mock compatibility test,
   then an explicitly authorized live smoke.

This example deliberately contains no real endpoint, account, provider brand,
or credential.
